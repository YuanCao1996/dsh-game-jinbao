# 独立桌面版 0.3.64

发布：2026-11-27（CST）

## 悬浮窗宽度

- 默认大框宽度 `380 → 300`；
- XAML 最小宽度 `420 → 280`，首次打开不会被撑宽；
- 记住用户自行拖动后的宽度（阈值从 420 降到 280）。

## 更新失败恢复

- 失败标记不再让同一版本永久卡死；
- 设置页「重试更新」清空 `updates/rejected.json` 后重新检查/下载；
- 下载失败、安装失败都可直接重试，不再只能重新下载整包；
- 保留增量更新，本版补丁约 98 KB。

## 构建修复

- 补提交运行时依赖：`audience-agent.mjs`、`audience-task-agent.mjs`、`collector-*.mjs`、`node-*-agent.mjs`，避免清洁构建缺文件。
