# 独立桌面版 0.2.52

发布：2026-11-19 22:1x（CST）

## 需求

「很多消息都是一整段，看着费劲；能不能拆成多个口语短句，像边想边说——既省时间又更像真人。」

## 改了什么

### 1. 提示词：要求短句、按行分开

- 自动播报（`auto-coach.mjs`）：从「用 2 至 3 句」改为「分成 2~3 个短句，每句不超过 20 字，用换行分开——
  先说现在做什么，再补一句为什么或注意什么；像边想边说，不必一次说全」；
- 云端任务角色说明（`cloud-agent.mjs`）：从「40—60 字，最多两句」改为同样的短句要求。

### 2. 收敛逻辑：按句子切，不在括号/逗号中间硬切

`condenseAdvice()` 重写：

- 按 `。！？!?` 切句，最多 3 句，每句一行；
- **不**在逗号或括号中间切（0.2.51 试过硬切，切出「下一件优先买」「：智慧末刃（2900」这种碎片，更难读）；
- 末句缺标点时补句号；整条超过 90 字时从末尾丢整句，而不是切半句。

效果对比（用真实播报回放）：

```
原文：下次买无用大棒，合成灭世者之帽来堆法强呀。复活后跟近战清线打反手，躲开巫师帽凝滞和收集者处决哦。
新版：下次买无用大棒，合成灭世者之帽来堆法强呀。
      复活后跟近战清线打反手，躲开巫师帽凝滞和收集者处决哦。

原文：先用雪球贴脸，技能命中让蜜蜂炸开，小法要留雪球先手；跟祖安狂人往前压吧。下次购买优先帽子、中亚呀。
新版：先用雪球贴脸，技能命中让蜜蜂炸开，小法要留雪球先手；跟祖安狂人往前压吧。
      下次购买优先帽子、中亚呀。
```

单句超长（比如带括号的整句出装）会保持完整一行，不再切碎。
