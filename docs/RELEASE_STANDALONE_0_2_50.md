## 一、同一条建议不再反复播

**现象**：昨晚 `postAugment` 触发 9 次，22:57 / 23:02 / 23:06 三条都在说「雪球贴脸 + 跟祖安狂人往前压」。

**为什么之前没拦住**：三条的措辞差别很大（2-gram 相似度只有 0.11–0.16），任何"文本相似度"阈值都抓不到；
真正重复的是**意思**。

**修法（两层）**：

1. **提示词带上上一句**：自动建议的 prompt 里加入「刚才你已经说过：『…』。这次只补充新信息，
   不要重复同一句建议；没有新东西就说得更具体」，让模型自己换角度；
2. **逐字重复兜底**：同一阶段、90 秒内、双方都 ≥16 字、相似度 ≥0.8 时直接不播（记 `skip/duplicate_advice`）。
   阈值刻意收窄——只拦「换个标点又播一遍」，不误伤换说法的建议。

**验证**：新增 `auto-coach-repeat.test.mjs`——让模型连续两次吐同一句话，断言第二次不写播报、
且第二次提问里带「刚才你已经说过」。另有一条单测确认相似度只拦逐字重复。

## 二、「同一轮海克斯起两个 watcher」其实是记录假象

昨晚看到 5 组里 2 组同 `startedAt` 的 `card-watch-*` 目录，我最初判断是重复拉起 watcher。
查代码后是**元数据写错了地方**：`writeCardWatchMeta` 会把同一份 meta 写进**所有**最近修改的
`card-watch-*` 目录，于是运行日志里看起来像两个 watcher，其实只有一个。

**修法**：抽出 `pickCardWatchDir(names, startedAt)`，只写「时间戳离本轮开始时间最近」的那个目录
（±5 秒窗口，无时间戳的归档目录一律不碰），collector 改为调用它。

**验证**：`card-watch-meta.test.mjs` 覆盖本轮早 349ms 的目录、下一轮晚 2.7 秒的目录、过期目录、
归档目录四种情况。
