# 独立桌面版 0.2.43

发布：2026-11-18 21:3x（CST）
通道：independent standalone

## 真正的故障（以及它为什么藏了七版）

「日记暂时读不出来」**不是网络问题，也不是凭证问题**——是 `diary.html` 里的一行手误：

```js
const editedNote=diaryEdited;      // 本该是 $('diaryEdited')
```

成因：我用 PowerShell 双引号字符串做批量替换，`$('...')` 被 PowerShell 当成子表达式吞掉，
写出来成了裸变量。页面是 `'use strict'`，`renderEntry` 每次渲染到这一行就抛
`ReferenceError`，被外层 catch 接住 → 显示错误面板。于是**从 0.2.36 起，每一篇日记都渲染到一半就中断**：
标题、日期、段落已经填进 DOM，然后正文面板被藏起来、错误面板亮出来。「重试」永远无效。

之前 0.2.42 的「凭证自愈」修的是一个真实但次要的问题；这一版才挖到主因。

## 修法

- `const editedNote=$('diaryEdited');`
- 全页扫描确认没有第二处同类手误（`=diaryXxx;` 裸引用为零）
- **新增回归测试**：把 `renderEntry` 抽出来放进最小 DOM 桩里**真执行一遍**（带样例日记），
  断言标题/写于/涂改标记都被写上。字符串存在性检查永远抓不到运行时 ReferenceError，
  只有真跑函数才能抓住——坏代码在这个测试下当场爆。
