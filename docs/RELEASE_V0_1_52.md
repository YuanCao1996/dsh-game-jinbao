# v0.1.52

## 播报不再编造英雄

人名只能取自本局双方名单；同一个英雄也不能用称号和本名各写一遍。

真机事故：敌方名单是「解脱者、黑暗之女、祖安狂人、不屈之枪、河流之王」，
播报却写成「敌方安妮、乐芙兰、黑暗之女三法伤」——乐芙兰那局根本不存在，
安妮和黑暗之女还是同一个英雄。现在播报前会做人名校验：越界或重复命名直接拦下，
原文留在 rejected 字段里供复盘，不会显示也不会播报。

## 语音只念屏幕上的开头

旧实现遇到超长首句会跳过它去念后面那句，实测 47/75 条播报文本被改写、8 处明显截断
（524 字被念成 58 字、113 字只剩 65 字）。现在改为首句优先，过长就在标点处截断加省略号；
完全没有句读的超长文本仍然不播。

## 其他

- 对局回忆补齐 firstBlood 字段（之前缺失，成就统计读不到）
- 每局锐评限长到一段：主评 + 最多一条上下文
- 播报依赖指纹加入我方名单，便于事后核对队友名
