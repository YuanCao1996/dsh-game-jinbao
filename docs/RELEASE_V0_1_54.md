# v0.1.54

## 主播模式（B站弹幕）

- 观众弹幕经筛选后进入战况页：默认只回应带「@金宝」的弹幕，可选含「问」字或全部弹幕。
- 观众消息带「观众」标签与昵称，和玩家自己的提问区分开；观众回复只上屏、不朗读。
- 可用当前对局数据回应观众（战绩 / 下一件 / 海克斯 / 金币 / 对面），查不到就如实说不知道。
- 设置页新增独立分区，默认关闭；关闭时不影响任何现有逻辑。只需要直播间房间号，不需要开发者资质。

## 互动更有人味

- 买装备、选海克斯后立刻给一句反馈：听劝就夸，不听就调侃，四种导师语气不同，连续不听会升级。
- 每局补上开局问候、阵亡反应（最多 3 次、间隔 45 秒）、结束语（分胜负）与长时间沉默兜底。
- 战术建议优先，人味句子不会盖住战术播报。

## 出装计划不再一局三变

- 同一局只出一份六件顺序；已买的装备不再出现在计划里。
- 已有计划时必须沿用，改路线要说明理由（此前进一局生成 3–4 套互相矛盾的顺序）。

## 阵亡时不再谎报血量

- 倒地后不会再说「你还剩1%血，先回城补血」；要提血量只能说「倒下时是X%」。
- 越界的播报会被拦下，不显示也不播报。

## 聊天失败说得清原因

- 服务端不可用、响应超时、限流、登录失效分别有明确提示，不再只有「分析失败」。
- 手动提问遇到上游故障时会更快给出结果，不必等满一分钟。

## 其他

- 老日志兼容：英雄与 KDA 放在 state 顶层的对局，回忆不再丢 KDA 与已选海克斯。

更新需要正常退出金宝后应用。对局中不会强制安装，安装后确认运行版本为 0.1.54。
