# v0.1.53

## 自家海克斯不再丢

两条独立原因，这次都修了：

1. **聊天公告用「你」代替英雄名**：客户端把自己的选择写成「你 已质变了 X」，
   过去归因拿不到英雄名，记为 unknown，导致「本局已选」永远为空。
   现在主语以「你」开头时归属记为自己（「你们」这类他人措辞不算）。
2. **卡牌判定失败时静默丢弃**：卡牌监视器没判定出来时，过去只在有两帧图时留日志，
   其余情况直接返回；这一轮随后被关掉，但没有确认弹窗，玩家 4 次三选一全丢。
   现在无论有没有图都记一条 undecided，并把这一轮关掉，弹出「刚才选了哪个」让玩家确认。

## 语音「中断」不再误报

念完时刚好超过 20 秒有效期，过去会被记成 interrupted（实测一局 11 条「中断」多数是误报）。
现在只有真正取消才算中断，并记录原因（cancelled / scope_changed）。

## 老日志兼容

英雄与 KDA 放在 state 顶层的对局，回忆不再丢失 KDA 与已选海克斯。

## 回归测试

新增端到端用例：聊天「你」→ 本局已选 → 对局回忆（3 项）；
三选一判定失败必弹确认（4 项）；聊天归属（12 项）；语音（15 项）；人名校验（6 项）。

更新需要正常退出金宝后应用。对局中不会强制安装，安装后确认运行版本为 0.1.53。
