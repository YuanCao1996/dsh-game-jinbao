## 三、服务端提示词（云端，不在本仓库）

文件：服务器 `runtime-backend/agent_dsh/runtime/worker.mjs`（`policy.rules` 拼接）

- 本轮是时效优先的即时决策：最多调用一个工具，不要检索资料或联网，直接依据已有事实给出结论。
- 用户明确要求保存或删除偏好时，调用 manage_user_memory；fact 和 quote 逐字引用本轮用户原话，status=ok 才代表完成。
- 需要时先调用 experience_list 查看玩家私有经验；发现某条与当前版本或实际对局明显不符时，用 experience_edit 修订：source 逐字引用原经验，to 写修订后的结论，reason 说明依据。只能改私有经验，共享经验不在此列。
- 游戏攻略问题包括英雄、羁绊、装备、强化符文、阵容、运营和玩法等，不限于赛季；先检索本地，不足再联网。
- 截图是采集时间的观察，不是确证状态；候选不是已拥有，未知数值不猜。

## 四、维护提示

- 改口吻/角色：只改 `game-roles.mjs` 的 description 与 instruction，不要在各处散改。
- 改播报长度：`roles.mjs` 的 `briefSpeech` 负责把建议压到播报预算内，界面文本不受影响。
- 改错误话术：`chat-errors.mjs` 一处改动，悬浮窗、手机同步、设置页共用。
- 云端与本地两套 agent 的提示词不同源：云端在服务器 worker.mjs，本地 BYOK 在 `tools/cloud-desktop/local-agent.mjs`。
