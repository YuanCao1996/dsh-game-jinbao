## 8. 目前还没有话术的场景

- 连杀被终结、五杀被抢：事件流里有，但没有口头反应；
- 拿龙 / 拆塔 / 破水晶：只有截图和事件记录，没有一句即时反馈；
- 对线被单杀 3 次以上、被压 2 级：没有「要不要换线/求支援」的轻提示；
- 段位/晋级变化、英雄首次上手、版本更新提醒：完全没有；
- 队友挂机/掉线、投降投票：没有反应。
