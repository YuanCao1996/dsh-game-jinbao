# 多杀夸奖：分段模板（2026-11-21）

## 旧写法 vs 新写法

旧：每个等级两句固定短句，最多 20 字。
```
双杀，稳住这个节奏。
三杀！手感回来了，接着打。
```

新：**叹词 + 你 + 多杀 + 反应 + 夸奖 + 被击杀者 + 幽默说法**，一句 30–40 字。

```
哇塞，你这波三杀把我看愣住啦，牛呀！对面的安妮被你打成麻瓜了。
```

## 四个角色各一套词

| | 叹词 | 反应 | 夸奖 | 幽默（对被击杀者） |
|---|---|---|---|---|
| 金宝 | 哇塞 / 耶 / 嘿嘿 | 把我看愣住啦 / 看得我眼睛都直了 / 我手都拍红啦 | 牛呀 / 太厉害啦 / 你太猛啦 | 被你打成麻瓜了 / 话都说不出来 / 直接不吭声了 |
| 柳如风 | 不错 / 很好 | 节奏拿得很稳 / 处理得很干净 / 时机掐得正好 | 干得漂亮 / 这就是执行力 / 值得记一笔 | 被打崩了节奏 / 完全接不住 / 只能往回缩 |
| 王霸天 | 漂亮 / 痛快 | 把对面按在地上打 / 一点机会都没给 / 气势完全压住了 | 够狠 / 就该这么打 / 我服了 | 连还手的余地都没有 / 直接被打穿了 / 看着都没脾气了 |
| 铁汁 | 行啊 / 好家伙 / 嘿 | 看得我直乐 / 我服了 / 真给我整不会了 | 可以啊 / 有东西 / 牛 | 被打得没脾气 / 话都说不利索了 / 直接摆烂了 |

被击杀者的连接规则：
- 1 人 →「对面的安妮」
- 2 人 →「对面的安妮和塞拉斯」
- 3 人以上 →「对面安妮、塞拉斯那几个」
- 复仇优先于点名 →「塞拉斯那笔仇报了。」
- 整句超过 60 字（语音单段上限）时，整段丢掉被击杀者部分，不切半句。

## 顺带修掉的一个数据缺失

诊断显示链上的 `victims` 永远是 `[]`：多杀事件本身不带"杀了谁"，而原来只从 `state.events` 反推，
事件流又只留塔/龙/团灭，所以 111 次 ChampionKill 一个都没进去。

修法：每次 `ChampionKill` 记进 `state.recentKills`（保留 16 条），多杀时取「同一击杀者、最近 15 秒」
的受害者，去重、去掉 `#标签`、名字截 8 字。

## 验证

回放 11-20 那局日志（2 次自己的双杀）：

```
哇塞，你这波双杀把我看愣住啦，牛呀！对面的是她让我面对疾风和芒果Kin9被你打成麻瓜了。
耶，你这波双杀看得我眼睛都直了，太厉害啦！对面的晨小呆和某些人丶某些事话都说不出来。
```

单测 12 项全过，含「叹词/多杀/夸奖/被击杀者/幽默」逐项断言与 60 字上限。
