# v0.1.56

## 新功能

- 收起形态左侧有了金宝的形象：待机时头发会轻摆、嘴保持闭合；播报时自动换另一套口型动画，跟着语音和字幕走。
- 形象会看对局状态：阵亡时头轻微下垂并变淡，失利时歪头，思考时极轻微倾斜，挂机十分钟后睡着，结算胜利会轻快上跳两下。
- 设置页「收起形态的人物形象」可开关，大小可选 44 / 56 / 72 / 88，默认 56（44 时脸太小看不清）。

## 修复

- 展开成大框再收起后，形象会一直张嘴：大框里播放时钟是停的，阶段会冻在「播放中」，现在按形态判定。
- 没有专属素材的状态（思考 / 胜利 / 失利 / 选人 / 候场 / 睡觉）会退化成一张静止图标、动画消失，现在统一退回待机那一套。
- 窄条偶尔变成透明空条、看着像悬浮窗消失：现在保留上一条消息，真空着才显示占位文字。
- 口型与播报不同步：字已打完、只在等阅读的时间里不再动嘴。

## 教练侧同期改动

- 播报口气更口语。
- 出装建议按游戏时间判活，对局结束后不再给过期建议。
- 对局日志静默时不出建议。

更新需要先正常退出金宝再应用；安装后请确认运行版本为 0.1.56。

## 插件线（DSH 插件安装）

- 装完插件后 DSH 启动时会自动拉起悬浮窗，不需要另外跑启动器；关闭 DSH 时一起退出。
- 如果同时装了独立版，两者会抢 3081 端口，请只保留一套在跑。
- 悬浮窗起不来时看两处日志：`<stateDir>\overlay-plugin.log`（插件记录，含跳过原因）与 `<stateDir>\overlay-diagnostics\*.log`（悬浮窗自身输出）。
