## 本次内容

- **设置页「测试功能 · 开黑队伍」开关**：勾选后写 `team-rooms.json`，**下次启动生效**；
  侧栏点灰色入口的提示也从「用 --team-rooms 启动」改成指向这个开关。
- **设置页地址固定**：优先上次用过的端口（默认 **3084**），被占用时自动退回随机；只有真的用上期望端口才记进
  `settings-port.json`（临时冲突不会污染下次选择）。顺手验证了**不带 `#` 也能打开**——页面会自己从
  `/api/setup-nonce` 取凭证（仅回环地址），所以可以直接收藏 `http://127.0.0.1:3084/`。
- **日记「第一篇」**：她刚来到这台电脑的那一天写一篇，好奇、兴奋、期待之后一起玩；只写一次。
  日期取「最早一篇日记 / 最早一次对局」里更早的那天再往前一天，没有记录就是今天。
- **写第一篇前先「打量」这台电脑**：CPU 型号与核数、内存、显卡、各盘容量与余量、屏幕分辨率、系统版本；
  字段白名单（序列号 / MAC / 用户名 / 路径一律不采），结果缓存在 `machine-profile.json`，只在第一篇发一次。

## 发布过程中修掉的两个坑

1. **`machine-profile.ps1` 没进包**：构建只跟着 import 图走，外部 `.ps1` 不在清单里 → 打包后采集直接失败。
   改成**脚本内嵌在 `.mjs` 里**（`-EncodedCommand` 传 UTF-16LE base64），不再依赖打包清单。
2. **PowerShell 输出中文乱码**：默认按控制台代码页输出，`Windows 11 家庭中文版` 变成乱码；
   脚本头部强制 `[Console]::OutputEncoding = UTF8`。
