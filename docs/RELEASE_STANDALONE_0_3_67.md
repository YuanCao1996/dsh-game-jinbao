# 独立桌面版 0.3.67

发布：2026-11-28（CST）
重点：修复装备建议失败重试风暴。

## 根因

- 开局出装请求失败后，`opening` 只更新自身重试时间，没有同步全局 `lastAt/retryAt`；
- 同一 tick 紧接的常规出装分支仍满足冷却条件，于是继续请求；
- 模型连续失败时形成“失败 → 500ms 后重试”的循环。昨晚 `agent-activity.jsonl` 记录 1362 次 `task_failed`，峰值约 120 次/分钟。

## 修复

- `createEquipmentCoach` 增加连续失败计数与指数退避：5s / 10s / 20s / 40s / 60s 上限；
- 开局请求失败同时写入全局 `lastAt/retryAt`，常规分支不会立刻补发；
- 成功一次后失败计数清零；
- 新增测试：失败后连续 tick 不再重复请求，退避结束后才允许重试。

## 保留

- 0.3.66 的「重试更新」修复；
- 默认大框宽度 300；
- 全界面英雄常用名。

## 验证

- 本机 0.3.66 → 0.3.67 增量升级成功；
- `equipment-context` 新增测试通过；其余剩余失败为仓库既有的强化归属用例，与本次无关。
