# 独立桌面版 0.2.47

发布：2026-11-18 22:5x（CST）

## 改的是什么

战况页每条消息前面的「金宝」标签。

战况页是一条**混排时间线**：教练建议、你的问话、手机问话、开黑队友消息按时间排在一起，所以每条要有「谁说的」。
但单人对局里只有两个人，面板本身就是她的，于是每行开头都重复一遍「金宝」。

现在：

| 场景 | 行为 |
|---|---|
| 单人对局 · 她的消息 | **不标说话人**，只留 `时间 + 类别标签`（出装/团战/符文…） |
| 单人对局 · 你的消息 | 照旧 `你 · 电脑` / `你 · 手机` |
| 失败/未完成 | 照旧 `本次未完成` |
| 开黑群聊（`teamChatMode=team`） | **照旧全部标**：`金宝`、`阿伟 · 盲僧` |

实现：`$speakerName` 在单人对局且是教练消息时取空串，渲染处 `if(-not $repeatSpeaker -and $speakerName)` 跳过空标签。

## 验证

```
自测（真 WPF 跑一遍）：
  soloHidesCoachSpeaker      = true   （三条她的话 → 0 个「金宝」标签，正文三条都在）
  teamTimelineKeepsSpeaker   = true   （队伍模式 → 「金宝」「阿伟 · 盲僧」都在）
其余失败项与 HEAD 基线完全一致（resize/collapse 等需要真实窗口交互，本机跑不了），无回归
```
