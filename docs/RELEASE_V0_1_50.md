# v0.1.50

## 探索图鉴：回忆画廊

- 图鉴页改成**时间线**：最近的对局排在最前，按「今天 / 昨天 / M月D日」分组，胜负节点用橄榄绿与砖红区分。
- 每条回忆含：英雄、时间、等级、胜负、时长、KDA、这局的海克斯、三杀/团灭等高光，以及金宝的一句话。
- 点任意一条回忆或英雄卡片，右侧抽屉展开该英雄的全部对局。
- 页面换成手账质感：纸张受光、颗粒噪点、暗角、发丝线边框，字重与数字对齐重新处理。

## 每局回忆更完整

- 对局结束自动记录 KDA（13/12/16）、等级、时长、胜负（Win/Lose）、海克斯与高光。
- 旧版本记录缺字段时，会从本机对局日志自动回填，不再显示「KDA —」。

## 修复

- **收起悬浮窗崩溃**：脚本里混进了一行 JS 注释，收起时执行到就抛异常；另有一处 `else` 链在加日志时被拆断。均已修正。
- **调整大小后窗口消失/自己弹回**：播报空闲时不再自动收起；窄条模式播完保持字幕条并显示「金宝待命中」。
- **语音播到一半被截断**：20 秒有效期不再中断已在播放的条目，单条上限放宽到 80 字。
- **强化识别**：卡片还在候选时不记为已选；面板关闭却没有判定时弹出确认面板（默认推荐排名最高的那张）；无归属识别的去重窗口从 6 秒放宽到 30 秒。
- **多杀播报**：多杀数量改由游戏事件的 KillStreak 决定，不再出现三杀说成双杀。

## 其他

- 事件流放开：装备更新、疑似强化识别、游戏内聊天框 OCR 的买卖与强化公告都进入动态。
- 选人阶段新增一条独立消息：我方阵容分析（中文职业）+ 你的角色定位。
- 阵亡回合的播报必须点名一件具体装备，并说明理由。
- 新增语音审计日志：`logs/speech.jsonl` 记录原文与实际播报文本，便于比对。
- 设置页左侧导航重新分组，开黑队伍入口常显。

验证：overlay / speech / companion 单测通过；本机对局日志回填验证 KDA 13/12/16、Lv17、负、三杀与团灭。

更新需要正常退出金宝后应用。对局中不会强制安装，安装后确认运行版本为 0.1.50。
