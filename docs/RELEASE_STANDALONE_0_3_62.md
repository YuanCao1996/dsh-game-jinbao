# 独立桌面版 0.3.62

发布：2026-11-27（CST）
重点：OCR 队伍聊天显示名改为英雄常用名，不再显示玩家名/称号。

## 改动

- `chat_events` 的 `team_chat` / `ping` 显示名改为：
  1. 发言行携带的 `champion` 转常用名；
  2. 缺失时用 `championLabel(playerName)` 从本局名单反查英雄；
  3. 仍无法映射时显示「队友」/「你」，绝不回退玩家名。
- `championLabel` 统一剥离英雄称号，只保留常用名（击杀、团战等显示同步生效）。
- 新增测试：`队伍 OCR 聊天只显示英雄常用名，不显示玩家名或称号`。
